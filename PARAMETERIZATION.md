# curveRcore: Parameterization Reference

## Sprint 1 Deliverable — Model Math Foundation

### Convention (locked in, all three packages)

| Property | Value |
|----------|-------|
| `a` | Lower asymptote (baseline), always `a < d` |
| `d` | Upper asymptote (saturation), always `d > a` |
| `b` | Scale/slope, always `b > 0` |
| `c` | Inflection-point location (on the external x-scale) |
| `g` | Asymmetry (5-param only), always `g > 0` |
| `x` | Externally transformed (e.g. `log10(conc)`), passed as-is |

All models are **monotonically increasing** from `a` to `d`.

---

### Model Formulas: Old (curveRfreq) → New (curveRcore)

#### logistic4
```
OLD:  y = d + (a − d) / (1 + exp((x − c) / b))         b sign-dependent
NEW:  y = a + (d − a) / (1 + exp(−(x − c) / b))         b > 0 always
```
**Mathematically identical.** The two are algebraic rearrangements.

#### logistic5
```
OLD:  y = d + (a − d) / (1 + exp((x − c) / b))^g        b sign-dependent
NEW:  y = a + (d − a) / (1 + exp(−(x − c) / b))^g        b > 0 always
```
**Mathematically identical.**

#### loglogistic4
```
OLD:  y = a + (d − a) / (1 + (x / c)^b)                  b < 0 for increasing
NEW:  y = a + (d − a) / (1 + (c / x)^b)                   b > 0 for increasing
```
**Equivalent** (negating b flips x/c ↔ c/x). Requires `x > 0`.

*Domain note:* On log10-transformed x (which can be negative), loglogistic4 is
algebraically equivalent to logistic4. The fitting code should either skip it
or map it when `is_log_independent = TRUE`.

#### loglogistic5 (unchanged)
```
y = a + (d − a) · (1 + g · exp(−b · (x − c)))^(−1/g)    b > 0
```

#### gompertz4 (unchanged)
```
y = a + (d − a) · exp(−exp(−b · (x − c)))                b > 0
```

---

### Inverse Formulas (New)

| Model | Inverse x = f⁻¹(y) |
|-------|---------------------|
| logistic4 | `c + b · log((y − a) / (d − y))` |
| logistic5 | `c − b · log(((d − a) / (y − a))^(1/g) − 1)` |
| loglogistic4 | `c / ((d − y) / (y − a))^(1/b)` |
| loglogistic5 | `c − (1/b) · [log(((y−a)/(d−a))^(−g) − 1) − log(g)]` |
| gompertz4 | `c − (1/b) · log(−log((y − a) / (d − a)))` |
